# quadruped-robot-dog-urdf
High-fidelity URDF of LubLune's Arduino Robot Dog for MuJoCo &amp; Isaac Sim researchers. Converted raw 3D-printed STL meshes to smooth STEP files for clean assembly. Optimized to close the sim-to-real gap using precise joint constraints, 15% infill material densities, and a custom battery pack for accurate CoM calculations.
